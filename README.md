# UniSystem — Sistema de Gestão Acadêmica

Sistema CRUD completo desenvolvido utilizando Python + FastAPI no backend, Redis como banco de dados e frontend em HTML5, CSS3 e JavaScript.

## Tecnologias Utilizadas

- Python 3.11
- FastAPI
- Redis
- Uvicorn
- Pydantic v2
- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Cadastro de alunos
- Listagem de alunos
- Consulta por ID
- Atualização de dados
- Exclusão de alunos
- Validação de dados
- API REST
